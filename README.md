# 🎹 Пиано учител

Уеб приложение за учене на пиано. Нотите се движат по нотния ред, а приложението слуша през микрофона дали изсвирваш правилната нота навреме. Работи с акустично пиано.

**▶ Отвори:** https://aleksandrenko.github.io/piano-trainer/

## Какво има

- Движещ се нотен ред с имена на нотите и клавиатура, която показва кой клавиш да натиснеш.
- Слушане през микрофона: разпознава и акорди, засича кои клавиши си натиснал.
- Режими: „Изчаква ме“ (спира, докато не изсвириш правилно) и „В темп“ (с метроном и оценка на точността).
- Дясна ръка, лява ръка или двете; компютърът може да свири другата ръка.
- 🎚 Настройка: изсвирваш гамата До4–До5 и приложението научава шума в стаята, колко силно се чува пианото ти и дали е разстроено.
- Песни в няколко секции: за една ръка (начинаещи), „Магия“, и 4 нива на трудност.
- Внасяне на собствени MIDI файлове.

## Пускане локално

Това е един HTML файл без сглобяване (build). Микрофонът работи само по `https` или `localhost`:

```bash
python3 -m http.server 8795 --directory .
```

След това отвори http://localhost:8795.
